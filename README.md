Runs using python and Streamlit.

## Installation

Download as a zip file or clone using git

Install python if not already installed (I have used python version 3.14.5 while working on it).

Run below command in terminal or command prompt (pip should install dependencies automatically).

```bash
pip install -r requirements.txt
```

## Usage

Run following code in your terminal or command prompt

```bash
streamlit run app.py
```
